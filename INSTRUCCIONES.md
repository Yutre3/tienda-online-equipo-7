# Instrucciones

La guía completa y actualizada de instalación, base de datos, Visual Studio Code,
ejecución, pruebas y trabajo grupal está en [README.md](README.md).

Comandos principales, ejecutados desde la raíz del proyecto:

```bash
python -m scripts.crear_base_datos
python -m scripts.probar_conexion
python -m scripts.verificar_sistema
python -m unittest discover -s tests -v
python app.py
```
